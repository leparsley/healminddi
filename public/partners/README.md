# 合作机构标识

本目录保存 10 家机构的官网原始标识，按项目方要求用于机构识别。
心脑智愈暂无可靠原图，保留文字占位。

- 图片不裁切、不重新绘制、不改色，使用 object-fit: contain 保持原比例。
- 上海电机学院、华东师范大学使用大学校徽；其余使用对应机构官网字标组合。
- 上海交大心理学院、上海市精神卫生中心的官网白色字标采用深色衬底。
- Vite 的 import.meta.env.BASE_URL 用于适配域名根路径或部署子目录。
- 加载失败自动回退为文字。新增图片时同步更新 app/partners-data.ts。
- 机构标识不改变合作状态：仅前三家企业为已确认合作方。
